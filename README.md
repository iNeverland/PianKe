# 🎬 PianKe（片刻）

一款离线优先的个人影视日记应用，用来收藏想看的作品、记录观看过程与留下感受。

## 功能特点

- **影视收藏**：管理电影、剧集、纪录片、综艺和动画；支持海报、标签、评分、类型、地区等信息。
- **追剧进度**：按季、按集记录进度，快速跳集；看到最后一集时，可确认“看完并写记录”。
- **观影日记**：自动保留进度和状态变更，按时间线回顾观看轨迹。
- **追剧记录**：手动写下观看感受、评分和短评，与自动日记独立保存。
- **想看清单**：先收藏感兴趣的作品，随时切换为在看或已看完。
- **数据统计**：查看观影趋势、类型偏好、评分分布、地区分布与日记热力图。
- **本地掌控**：影视资料、日记和图片保存于本地文件夹；支持完整备份及 CSV 导入导出。
- **舒适使用**：支持浅色、深色与跟随系统主题，以及搜索、新建等快捷操作。
