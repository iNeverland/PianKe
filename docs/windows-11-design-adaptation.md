# 片刻 Windows 11 Fluent 适配说明

本次界面适配依据《Windows 11 UI Design Guidelines》执行，目标是在保留片刻的橙色品牌记忆点的前提下，让桌面端层级、控件和动效更贴近 Windows 11。

## 已落地的设计决策

| 规范 | 片刻中的落地方式 |
| --- | --- |
| 4 epx 栅格 | 间距与控件高度收敛到 4 的倍数：8、12、16、20、24、32、40、48。 |
| 4px / 8px 圆角层级 | 按钮、输入框、行 hover 等页面内控件使用 4px；菜单、对话框、图表容器等顶层表面使用 8px。 |
| 标准字阶 | 正文为 14/20，辅助文本为 12/16，分区标题为 20/28，页面标题为 28/36；中文优先 `Microsoft YaHei UI`，并以 `Segoe UI Variable` 作为 Windows UI 回退。 |
| Material | 页面和导航为不透明、低干扰的 Mica 感背景；仅菜单、下拉、提示等短暂表面使用 Acrylic 式模糊。模态框使用 Smoke 遮罩。 |
| Elevation | 内容卡保持扁平边框；仅浮层、提示和对话框提升阴影，避免将阴影作为装饰。 |
| 导航 | 将永久的玻璃胶囊改为侧边导航层，选中项由左侧强调条、背景和图标色共同表示。 |
| 动效 | 常规交互收敛至 167ms，按下反馈为 83ms；保留系统“减少动态效果”设置。 |
| 无障碍 | 保留并统一 2px 键盘焦点环；选中、错误、状态同时使用颜色、填充和文本，避免只依赖颜色。 |

## 品牌取舍

橙色仍是关键操作与当前导航状态的品牌色，但在深色主题中改为高对比浅橙，避免文字和焦点在深背景中失去可读性。影视海报、照片墙等内容资产维持原样，视觉更新只作用于应用 chrome 和信息层级。
